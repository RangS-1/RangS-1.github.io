Bash: Mencoba scripting terminal dengan Bash

Apa itu Bash? Bagaimana ia menjadi andalan developer dalam pekerjaan yang diulang-ulang?

#bash #terminal #shell

Apa itu Bash?

Bourne-Again Shell atau sering disebut Bash adalah Shell yang berfungsi sebagai penerjemah perintah terminal untuk sistem operasi .

"The single most important design decision: what you type at the prompt and what you write in a file share the same syntax."
— Brian Fox, pencipta Bash

Pada artikel ini, kita akan bahas tentang Bash, terutama pada bagian Scripting dengan Bash.

Bourne-Again Shell

Jadi apa itu Bash? Bourne Again Shell atau biasa disebut dengan Bash adalah penerjemah perintah pengguna untuk dijalankan oleh kernel. Kernel sendiri adalah inti dari sistem operasi yang mengatur memory, interrupt (input dan semacamnya) dan lain-lain.

Bash biasanya sering dijadikan sebagai default shell dalam sistem operasi linux, tetapi banyak juga yang menggunakan shell lain seperti fish dan zsh. Jika tidak menggunakan TTY, Bash sering digunakan dengan terminal seperti kitty, foot (aku tak tahu kenapa disebut foot) dan lain-lain. Oh ya, jika kau menggunakan laptop linux, kau bisa masuk ke TTY mode dengan Ctrl+Alt+F3, dan jika ingin kembali seperti semula tinggal tekan Ctrl+Alt+F1.

Scripting Bash

Kita masuk ke dalam Scripting Bash. Apa itu Scripting dengan Bash? yang dimaksud dengan scripting adalah membuat skrip yang bisa digunakan berkali-kali untuk pekerjaan yang diulang-ulang. Alasan utama membuat Script Bash tentunya agar lebih mudah dan tidak mengulangi pekerjaan yang sering diulang-ulang.

File script bash biasanya berakhiran dengan ekstensi .sh atau bahkan tidak menggunakan akhiran ekstensi sama sekali.

Membuat Backup Script

Di sini aku belajar dari AI, tapi disini aku tidak minta AI untuk membuat projectnya secara langsung melainkan dengan memberitahu dasarnya dan guide untuk script yang kubuat. Script pertama adalah backup.sh.

backup.sh ini adalah script untuk membuat backup folder tertentu. Di sini menggunakan perintah read untuk mengambil input dari user, yang dimana input user tersebut adalah nama foldernya. Setelah selesai maka script otomatis mengkompresnya menjadi file tar.gz.

Yang kupelajari adalah if condition. if condition di bash ini cukup unik, coba lihat kode berikut: 

if [ ! -d "$DESTINATION" ]; then
  mkdir -p "$DESTINATION"
  echo "folder $DESTINATION has been created"
else
  echo "folder $DESTINATION already created!"
fi

Bash menggunakan akhiran dan semacam array?, aku tak tahu kenapa seperti itu untuk bash. Akhiran di sini adalah if diakhiri dengan fi. Ini sangat mempermudah karena programmer tahu kapan sebuah if diakhiri, Meskipun akhirannya menggunakan if yang dibalik yang akan terasa agak aneh. Sejauh yang kutahu if condition yang diakhiri juga ada di bahasa pemrograman Lua. Kalau pada Lua seperti berikut: 

if ... then
  Do_Something
end

Membuat Script untuk update sistem.

Jujur saja aku agak bingung dengan cara kerja dari FreeBSD beserta ports collectionnya (ports collection tuh semacam koleksi resmi dari FreeBSD yang menyimpan Makefile dan lain-lain). Di sini akan kujelaskan sejauh pengalamanku. Untuk membuat package FreeBSD, masukkan perintah berikut: 

git clone https://git.freebsd.org/ports.git /usr/ports

Tunggu sampai selesai dan jika sudah selesai, masukkan perintah 

cd /usr/ports

Mengingat ini berada di file sistem, aku sarankan untuk berada dalam mode root. Setelah masuk ke folder ports, coba lihat foto di bawah ini, akan ada banyak sekali ports atau bisa dibilang aplikasi.

Setelahnya, cukup buat folder misalnya folder misc/namaaplikasi. Lalu di dalam folder tersebut, cukup buat Makefile dan isi dengan konfigurasi aplikasimu. Sebagai contoh di sini aku menggunakan project Ferminal yang kubuat dengan python. Kurang lebih isi dari Makefilenya seperti berikut: 

PORTNAME=ferminal
DISTVERSION=1.4.2
CATEGORIES=misc

DISTNAME=$(PORTNAME)-$(DISTVERSION)

MAINTAINER-rangga19sj@gmail.com
COMMENT=Custom Wrapper CLI to make your work faster
WWW=https://github.com/RangS-1/Ferminal

LICENSE=MIT
USE_GITHUB=yes
GH_ACCOUNT=RangS-1
GH_PROJECT=Ferminal
GH_TAGNAME=v$(DISTVERSION)

USES=python
USE_GITHUB=yes
USE_PYTHON-autoplist pep517
RUN_DEPENDS=
            $(PYTHON_PKGNAMEPREFIX)colorama>0:devel/py-colorama@$(PY_FLAVOR)
            $(PYTHON_PKGNAMEPREFIX)prompt-toolkit>0:devel/py-prompt-toolkit@$(PY_FLAVOR)

include <bsd.port.mk>

Inti dari kode tersebut adalah Makefile mengambil file dari Github release berdasarkan versi, lalu build python dengan autoplist dan PEP517. Setelah membuat Makefile, lanjut buat pkg-descr. pkg-descr berisi deskripsi dari aplikasi yang kau buat. Isi apa sajalah bebas.

Jika sudah membuat kedua file tersebut, cukup lakukan: 

make makesum

Nanti ia akan membuat file berada distinfo. Aku kurang tahu distinfo untuk apa. Setelah membuat distinfo, saatnya install dengan: 

make install clean

Nanti akan otomatis menginstall aplikasinya sekaligus buildnya, build tergantung dari source code yang kau buat, jika menggunakan C++ biasanya menggunakan CMake.

Akan ada folder dengan nama work-py312, jika folder tersebut sudah tergenerate, cukup lakukan: 

make package

File package FreeBSD akan tergenerate pada work-py312/pkg/namaaplikasi-version.pkg. Sekarang coba hapus dengan 

pkg remove namaaplikasi
pkg install namaaplikasi-version.pkg

Jika berhasil, artinya kamu sudah membuat package untuk FreeBSD dan bisa mengatakan "I Use FreeBSD BTW". Kau bisa membagikan file .pkg tersebut pada orang lain dan mereka bisa menjalankan perintah yang sama, dengan catatan mereka menggunakan FreeBSD.

Lisensi FreeBSD

Jujur saja aku penasaran kenapa MacOS tidak menggunakan Linux sebagai Kernelnya. Ternyata alasannya adalah lisensi. Linux menggunakan lisensi GPLv2 yang mengartikan bahwa perusahaan dapat menggunakan Linux, tetapi mereka harus membuatnya tetap Open Source alias kode sumbernya terbuka dan bisa dilihat oleh orang lain. Apple kurang suka dengan hal ini, karena itu ia memilih FreeBSD karena lisensi FreeBSD bersifat permisif, artinya perusahaan boleh menggunakan dan membuatnya tertutup.

Karena itu Apple kini menggunakan Berkeley Software Distribution sebagai kerangka utama dalam terciptanya Darwin, MacOS maupun Iphone. Jadi Iphone yang biasa digunakan merupakan turunan dari BSD.
